### P1 重启验证（真实接管落盘 → 稳定）
- 触发 `POST /dsh-supervisor/regen`（真实 LLM 圆桌）3 轮：
  - 第 1 轮 `rt-1788425378223-*`：opinions=3（strategy/critic/verify），consensus 为裁决文本。
  - 第 2 轮 `rt-1788425479943-*`：opinions=3，独立轮次 & 唯一 roundId。

## P2（图可视化）—— 完成 ✅
- 新增「圆桌记录」图视图（采用 01 语义）：节点=学院/共识/轮次，边=送入裁决/分歧/一致。
- 从 store `getRoundtables` 拉数据，渲染图（关系图 + 时间线）。
- **实现**：
  - `src/roundtable-graph.js`：纯函数 `buildRoundtableGraph(records)` → `{rounds,nodes,edges,summary}`（node 可单测，0 运行时依赖）。
  - `GET /dsh-supervisor/roundtables/graph?sessionId=`：宿主读 `getRoundtables` 后交纯函数构建图返回。
  - 客户端浮窗加「圆桌记录」切换按钮（可发现入口），拉图数据按轮次 timeline 渲染，分歧标注虚线边。
- **可测验收判据**（P2 Pass 需全满足）：
  - **G1** ✅：`getRoundtables(sid)` ≥1 轮记录能渲染成图（rounds/nodes/edges 非空）。
  - **G2** ✅（按实际参与集）：每轮 faculty 节点=实际参与学院数（主责+协作，非固定 5）+ 1 consensus + 1 round。
  - **G3** ✅：每个 faculty→consensus「送入裁决」边存在（=实际参与学院数）。
  - **G4** ✅：`verdict==='分歧'` 时存在 ≥1 条 faculty⟂faculty 虚线边；`verdict==='一致'` 时无。真实数据验证：仅分歧轮画 3 条虚线边，其余轮无。
  - **G5** ✅：图视图有可发现入口（supervisor 浮窗「圆桌记录」按钮）。
  - **G6** ✅：多轮按 `at` 时间线排列，可逐轮展开查阅（`<details>`）。
- **验证方式**：`test/roundtable-graph.test.js` 合成记录跑通 G1-G4/G6（5 测试）；真实接管记录 node 直接构建图（3 轮，分歧轮 divergence=3）抽查 G5/G6。
- **测试证据**：supervisor 全量 **32/32** 通过（新增 7 项 roundtable-graph/客户端入口 测试）。
- **上线后核验**：重启后 `GET /dsh-supervisor/roundtables/graph?sessionId=...` 实时返回真实图（rounds=3,nodes=14,edges=11，分歧轮 divergence=3）；客户端「圆桌记录」按钮可发现入口已挂载。
