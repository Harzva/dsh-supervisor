# Submission release notes

The prepared submission-material version is `harzva-supervisor` 0.4.1. It adds public listing/policy links, brand assets and structured review materials while retaining the 0.4.0 execution behavior. Existing live behavior evidence belongs to 0.4.0 and its development-cache variants; it is not relabeled as a new 0.4.1 model run. The final manifest and ZIP must be frozen and compared with that baseline. The local development cache suffix is not a public release number.

The plugin contains five skills: setup, supervise, execute, faculty-review and handoff. The desktop stdio MCP panel exposes seven tools for explicit project binding, status, native model discovery, execution defaults, dispatch control and cancellation. Model and reasoning settings affect new proposals only, with actual selections shown from native receipts. Existing grants retain their digest, workspace, model, effort, acceptance checks and attempt cap.

The execution chain persists dispatch intent before native queue submission, independently checks artifacts and records progress checkpoints. Cancellation closes dispatch first, requests interruption and preserves uncertainty when confirmation is missing. Roles and migrated DSH routes are responsibility metadata; they do not create separate provider models. Native Goal state and unrelated conversations are left to the host.

SDK dependencies and license notices are bundled. The prior DSH package remains a separate `dsh-supervisor` 0.2.4 project; this submission is not a DSH marketplace release and does not claim that an OpenAI public listing already exists.

For the 0.4.0 baseline, local installed-native discovery and model/effort/CAS/isolation checks, a real independently accepted file job, a real in-flight cancellation, and twenty AppBridge UI checks were recorded. The native desktop window was not directly clicked during automated verification. Final public listing metadata, policy pages, review recording, partner eligibility and submitting identity must be verified separately.
