## 风险

| 风险 | 对策 |
| --- | --- |
| 现有 Client 是手写大 bundle | 先局部纯函数化，功能稳定后再迁移构建链 |
| 冷会话缺少运行态事实 | 以持久分配为权威，事实缺失时不随意重分配 |
| 会话创建逻辑被重复实现 | 抽取宿主供应服务，API 与导师共用 |
| 页面断开导致交接半完成 | Host 保存状态和固定目标 ID，允许恢复 |
| Handoff 包含敏感信息 | 结构化白名单、长度限制、禁止原始日志落盘 |
